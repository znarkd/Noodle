# Noodle Privacy
NoodleApp is a demonstration web application designed to showcase Noodle’s capabilities. It allows users to load data from their local disk, Google Drive, or external websites. Users may view and revise their data with the app.  Data is stored only when the user explicitly chooses to export it—  either back to Google Drive or to their local device.

NoodleApp does not collect user information, cache data, transmit data to external services, or use cookies.
