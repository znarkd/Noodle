Convert a CSV File to a Noodle Database


Select an output specification file that defines the structure of the new database. Each line in the specification file contains a comma-separated field definition.

Each field definition requires four attributes: Field Length, Data Type, Field Name, and Display Width.
  1. Field Length (Bytes)
    Specifies the number of bytes allocated to the field in the Noodle database.
  2. Data Type
    The first character must identify the field type using one of the values below.
Type Description
B - Binary Integer Whole numbers such as 1, 58, -25, or 3000.
R - Real Number Floating-point values such as 1.245, -3.0, or 10.5.
D - Date Date values such as 7/22/93 or July 22, 1993.
M - Date and Time Date and Time in milliseconds
Z - Zero-Filled Integer Fixed-width numbers such as 0123, 0001, or 5432.
T - Tabular Text or character string data.
E - Elemental data Data stored as found in the source file
T types must include a numeric suffix indicating the associated table number.
R types must include a numeric suffix specifying the number of decimal places to display.
  1. Field Name
    An alphanumeric identifier. Names may contain letters and numbers and should begin with a letter.
  2. Display Width
    Specifies the column width used when displaying the field.
Example
2,B,Seq,2
2,T3,Item,16
5,E,Space,5
1,T1,Category,9
1,B,Count,5
